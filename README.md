# 🚀 Colab to Google Drive File Transfer

A sleek and minimal tool to transfer files from Google Colab directly into your Google Drive. Built for speed, simplicity, and smooth workflows.

---

## ✨ Features

- ⚡ One-command setup
- 🗂️ Clean file picker interface
- 🔒 Safe and secure transfer
- 🎯 Minimal, premium UX

---

## 🧪 Use Case

Want to save your Colab outputs, trained models, or datasets directly into Drive?  
This tool does that — instantly. No copy-paste. No download-click madness.

---

pip install ipyfilechooser
